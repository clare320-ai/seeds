# 菜籽仔（tshài-tsí-á）

菜籽仔是台語「蔬菜的種子」。走路、收集菜籽仔、沿路種花、到景點拍明信片的散步遊戲（第一版）。

## 放上網路（GitHub Pages，免費）

iPhone 的定位與動作感測器只在 HTTPS 網址下運作，所以要先把這個資料夾放上網。

1. 到 github.com 註冊並登入。
2. 右上角「+」→ New repository，名稱填 `yaya`，選 **Public**，按 Create repository。
3. 在新的 repo 頁面點「uploading an existing file」，把這個資料夾裡的所有檔案
   （index.html、places-hsinchu.js、places-taichung.js、sw.js、manifest.webmanifest、icon-180.png、icon-192.png、icon-512.png）拖進去，按 Commit changes。
4. 到 Settings → Pages，Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
5. 等一兩分鐘，網址會是 `https://你的帳號.github.io/yaya/`。

之後要更新，只要再上傳新的 index.html 覆蓋即可。

## 裝到 iPhone

1. 用 **Safari** 打開上面的網址。
2. 按下方分享按鈕 →「加入主畫面」。
3. 從主畫面的圖示開啟，按「開始散步」，允許「動作與方向」和「位置」。
   - 如果沒跳出定位詢問：設定 → 隱私權與安全性 → 定位服務 → Safari 網站 → 使用 App 期間。

> 一定要從主畫面開啟：iOS 會把一般 Safari 分頁的網站資料在 7 天沒用後清掉，加入主畫面的不會。

## 玩法重點

- **計步**：畫面亮著時用動作感測器即時計步。放口袋請按「口袋模式」，畫面全黑但保持亮著繼續計步，長按圓圈解鎖。
- **Apple 健康同步**：螢幕關著時走的步數，按右上「♥ 同步健康步數」補回來。第一次要照畫面說明在「捷徑」App 建一個叫「菜籽仔步數」的捷徑（約 1 分鐘）。
  之後：按「執行捷徑」→ 回到菜籽仔 → 按「貼上步數」。同一天重複同步不會重複計算。
- **主角菜籽仔**：地圖正中間是陪你散步的菜籽仔，走路時畫面跟著牠移動。點牠可以換一隻；拖動地圖後 15 秒會自動回到牠身上。
- **拔菜籽仔**：種子走滿步數會響鈴提醒，到菜園按「拔起來」，按住往上滑把菜籽仔拔出來（中途放手會縮回去）。背景音樂和音效可以在菜園最下面分別關掉。
- **地點**：彩色圓章是 OpenStreetMap 上的店家、廟宇、公園、藥局診所、活動中心等；小招牌是街角點；小黃花是野生點；方形「景」是景點。走到 45 公尺內（景點 150 公尺）點一下就能收集。同一個點 4 小時後可再收集。
- **種子**：前 3 顆在菜園跟著步數長大，走滿就能拔起來。在哪類地點撿到，就會戴對應的飾品；顏色（香火、稻穗、溪流、竹風）隨機。
- **種花**：打開後每走 10 公尺種一朵當季的花，用掉 1 片花瓣。
- **明信片**：在景點打卡，或在郵局頁「在這裡拍明信片」，照片會印成郵票風明信片，可以分享到 LINE 或存進相簿。
- **備份**：菜園頁最下方「備份存檔」，偶爾做一次。

## 測試用

網址後面加 `#sim`，點地圖就會模擬走過去（不需要真的出門）。

## 內建地點

伺服器忙碌或沒網路時也看得到：
- `places-hsinchu.js`：新竹火車站方圓 3 公里，2,663 個真實地點＋約 580 個街角招牌（檔案裡有 1,936 個，遊戲只取約三成）（城隍廟舊城區、新竹公園周邊、振興里、新興里、南大路沿線、公園里、東園里較密）。
- `places-taichung.js`：台中太原車站方圓 3 公里，3,451 個真實地點＋約 1,130 個街角招牌（同樣取約三成），另有 9 個台中景點可打卡。

地圖放大到一定程度才會畫出地點（太遠看會顯示「放大地圖才看得到地點」）。

## 已知限制

- OpenStreetMap 的地點伺服器偶爾滿載，畫面會顯示「地點伺服器忙碌」，會自動重試；野生點和景點不受影響。
- 新竹景點座標是大約位置，若實際打卡範圍不準請告訴我調整。
- 計步演算法是自寫的，準確度需要實際走幾天校正。
